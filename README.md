# Gerenciador de Tarefas 📋

Uma aplicação web simples e funcional para gerenciar tarefas do dia a dia.

## Funcionalidades

- ✅ Adicionar novas tarefas
- 🗑️ Remover tarefas
- ✔️ Marcar tarefas como concluídas
- 💾 Persistência de dados (LocalStorage)
- 🎨 Interface simples e intuitiva

## Tecnologias

- HTML5
- CSS3
- JavaScript (Vanilla)

## Como usar

1. Abra o arquivo `index.html` no navegador
2. Digite sua tarefa no campo de entrada
3. Clique em "Adicionar" ou pressione Enter
4. Para marcar como concluída, clique na tarefa
5. Para remover, clique no botão "X"
